### 2. Implemented Components & Hooks

#### 2.1 `RatingStars.jsx` (`src/features/reviews/RatingStars.jsx`)
- **Dual Mode:** Supports both read-only display and interactive 1–5 star selection.
- **Accessibility:**
  - Read-only: `role="img"` with descriptive `aria-label="X.X out of 5 stars"`.
  - Interactive: `role="radiogroup"` with individual star buttons having `role="radio"`, `aria-checked`, keyboard focus ring, and `aria-label="X stars"`.
- **Fractional Display:** Accurately renders partial star fills using clip paths in read-only mode.
- **Bounds Enforcing:** Ratings are strictly clamped between 1 and 5.

#### 2.2 `ReviewSummary.jsx` (`src/features/reviews/ReviewSummary.jsx`)
- **Server Authority:** Consumes `ratingAverage` and `ratingCount` directly from server-persisted Product props.
- **Zero-Review Neutrality:** When `ratingCount === 0`, clearly displays `0.0` with `"No customer reviews yet"` and a `"New Product"` badge without fabricating placeholder averages or false high ratings.
- **Zero Computation:** Avoids any client-side array reduction or recomputation of review score metrics.

#### 2.3 `ReviewCard.jsx` (`src/features/reviews/ReviewCard.jsx`)
- **Presentation:** Displays author name initial avatar, reviewer name, verified buyer badge (`Verified Buyer` pill), fractional star score, creation date, optional title, and long-body word-wrapping.
- **Owner Action Guard:** Shows `Edit` and `Delete` action buttons only when `currentUser._id === review.user._id` (or `review.user`). Hidden completely for guests and other users.
- **Privacy Protection:** Strictly omits email, phone number, password, full shipping address, and order ID from the DOM.

#### 2.4 `ReviewForm.jsx` (`src/features/reviews/ReviewForm.jsx`)
- **Dual Mode:** Seamlessly supports creating a new review or editing an existing review.
- **Validation UX:** Real-time client-side character length limits (Title max 120, Body 10–2000 chars) with visible countdowns and error indicators.
- **Domain Error Preservation:** Retains and displays specific backend domain error messages (`403 REVIEW_PURCHASE_REQUIRED`, `409 REVIEW_ALREADY_EXISTS`) without generic masking.
- **Strict Payload Isolation:** Form submission transmits ONLY `{ rating, title, body }`, preventing injection of `productId`, `userId`, `orderId`, or `isVerifiedBuyer`.
- **Guest Barrier:** If unauthenticated, displays a prominent sign-in prompt and triggers `onRequireAuth()`.

#### 2.5 `ReviewList.jsx` (`src/features/reviews/ReviewList.jsx`)
- **Lifecycle States:** Skeletons during initial load, friendly empty state with clear calls to action, and resilient error state with retry affordance (`onRetry`).
- **Toolbar:** Rating filter pills (`All Reviews`, `5 Stars` down to `1 Star`) and sort select (`Newest First`, `Oldest First`, `Highest Rating`, `Lowest Rating`).
- **Pagination:** Server-aligned pagination controls with `Previous` and `Next` buttons disabled according to `hasPrevPage` / `hasNextPage`.
- **Permanent Delete Confirmation:** In-line delete dialog with permanent deletion warning before executing mutation.

#### 2.6 `useProductReviews` (`src/features/reviews/review.hooks.js`)
- **State Management:** Encapsulates reviews array, server-provided pagination object, loading boolean, mutation state, active rating filter, and sorting keys.
- **Network Guards:** Bypasses network requests when `productId` is empty or invalid MongoDB ObjectId format.
- **Race Condition Protection:** Tracks active request IDs to ignore stale responses from superseded filter or pagination requests.
- **Action Dispatchers:** Exposes `createReview`, `updateReview`, `deleteReview`, and `refreshReviews`.

#### 2.7 Export Hub (`src/features/reviews/index.js`)
- Re-exports `RatingStars`, `ReviewSummary`, `ReviewCard`, `ReviewForm`, `ReviewList`, `useProductReviews`, `reviewService`, and review utility helpers.
